# OPMAS-001 — Oxygen Plant Monitoring & Analytics System

**Phase 1 — Read-Only Monitoring | CONFIDENTIAL**

## Project Structure

```
opmas-001/
├── backend/          # Laravel Web API & Dashboard (monolith)
├── database/         # Shared SQL 
├── frontend/         # React dashboard
├── docker/           # Container configs
├── scripts/          # Utility and deployment scripts
└── docs/             # Documentation
```

## Quick Start

### 1. Backend (Python Collector)
```bash
cd backend
cp .env.example .env       # fill in PLC IP and DB credentials
pip3 install -r requirements.txt
python3 main.py
```

### 2. Database
```bash
mysql -u root -p < database/migrations/001_create_schema.sql
mysql -u opmas_user -p opmas_db < database/migrations/002_seed_data.sql
```

### 3. Frontend (React)
```bash
cd frontend
cp .env.example .env.local  # set REACT_APP_API_URL
npm install
npm start
```

## Golden Rule
**The system is READ ONLY in Phase 1. No write commands shall ever be sent to the PLC.**
